## 📖 项目简介

这是一款集成 **WhatsApp、Telegram、Signal** 三大平台的实时翻译工具，专为跨语言沟通设计。

通过创新的 WS 子应用协议和原生窗口管理技术，实现消息的**内联翻译**、**智能发送**和**多账号管理**，让跨语言交流变得简单自然。

---

## ✨ 核心功能

### 🌐 三平台统一支持
- **WhatsApp** - 通过 WebView 嵌入，实时翻译聊天
- **Telegram** - 通过 Telegram Web 嵌入，支持群组翻译
- **Signal** - 通过子应用协议深度集成

### 💬 实时翻译体验
- **内联翻译**：收消息时原文下方直接显示译文
- **历史回填**：打开会话自动翻译历史消息
- **智能缓存**：已翻译消息不重复翻译，秒级恢复
- 
### ⌨️ 两段式智能发送
输入母语 → 按 Enter → 翻译填入发送框 → 再按 Enter → 确认发送

- 翻译结果先填入发送框，确认后才发送
- 支持**禁发中文**模式，防止误发母语

###  个性化设置
- **独立颜色**：每个平台可设置收/发颜色
- **字号调节**：翻译注解字号跟随滑块实时调整
- **实时生效**：修改设置后立即应用到已有消息

### 🔒 安全与隐私
- **本地运行**：所有数据存储在本地，不上传云端
- **账号隔离**：每个账号独立数据目录
- **版本保护**：防止 Signal 降级导致数据丢失

## 🛠️ 技术架构

### 核心技术
- **Electron 33.4** - 跨平台桌面应用框架
- **Node.js** - 后端逻辑与 IPC 通信
- **原生模块** - C++ 编写的窗口管理模块（Z 序控制）

### Signal 深度集成
- **Lookworld WS 子应用协议** - 通过 WebSocket 驱动补丁版 Signal
- **覆盖式嵌入** - 将 Signal 窗口铺到主窗口内容区上方
- **注入脚本** - 通过 `script.execute` 在 Signal 渲染进程执行翻译逻辑

### 窗口管理
- **Z 序钉住** - 通过 `SetWindowPos` 将 Signal 窗口插到主窗口正后方
- **焦点决策** - 渲染进程根据焦点位置智能调整 Z 序
- **周期维护** - 400ms 间隔检查，确保 Signal 始终可见

## 📡 技术细节

### Signal 集成方案

| 方案 | 可行性 | 说明 |
|------|--------|------|
| SetParent 真嵌入 | ❌ 不可行 | Signal 8.x 系统层拒绝 |
| **WS 子应用协议** | ✅ 采用 | Lookworld 方案，稳定可靠 |
| 外部 Z 序操作 | ⚠️ 受限 | 会破坏输入管线，已优化 |

### 关键修复记录

- **PS 死循环** - 进程树查询队列出队 bug 导致 CPU 100%
- **输入管线断开** - `--disable-gpu` 与透明窗口组合导致点击无效
- **g_signal 钩子** - 注入脚本必须定义全局钩子，否则会话打不开
- **注解自动恢复** - 窗口切换后 2 秒内自动重建翻译注解
